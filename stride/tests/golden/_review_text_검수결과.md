## 오탐 원인 (threshold 조정으로는 해결 안 됨)
1. 소제목·기준일처럼 짧은 문단 (7건): 번호 "(1)→(2)", "가→나"가 바뀌거나 짧아서 유사도가 낮게 나옴
2. 해마다 바뀌는 숫자 (6건): "금액 새로 등장" 규칙이 외화환산 각주·특허·통계 표의 연례 갱신을 잡음
3. 표현만 바꾼 문단 (3건): 같은 사실(회사명·지명·연도)인데 문장을 다시 씀
4. 표 재배치·짧은 문장 (2건)
5. 연례 통계 문단 (2건)

## 개선 제안
- 소제목 문단(번호 접두어 + 짧은 길이)은 신규 판정에서 제외하고, 번호를 지운 뒤 비교
- "금액 새로 등장"은 신규 판정 근거에서 빼고, "국가명·법인명 새로 등장"만 유지 (덕성 p71 같은 정탐은 국가명으로 잡힘)
- 유사도가 낮아도 고유명사(법인명·지명·국가명)가 모두 직전 보고서에 있으면 "표현 변경"으로 낮춰 표시
- 재현율 우선: 신규 표시는 LLM 추출 입력을 고르는 용도이므로 오탐은 비용만 늘고, 누락이 더 위험. 위 3가지는 정탐 3건을 유지하면서 오탐만 줄이는 방향
