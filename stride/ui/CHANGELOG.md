## 방향 수정 (2026-11-10) — 명세 v0.10, 와이어프레임 v1.9

- 기업 발굴 표: 기업, 해외 투자(국가·금액·단계), 해외 용도 조달, 원천÷소요, 원천−소요, 부채비율, 재무 위험 경고·변경, 검증. 기본 정렬 문구 표시, 원천 계열 정렬은 낮은 순·산출 불가 뒤
- 분포도: y축 원천÷소요, 1배 점선만
- 기업 상세: 카드 A 신호(출처 등급) → B 원천·소요(누적 막대 + 소요 합계 1배 점선, 항목 표) → C 차입 여력 → D 재무 위험, 값마다 기준일·계산식·출처 링크, 하단 고정 문구. 자금 공백 분해 막대 제거(검토서 절은 유지)
- 사용법 칩 예시 문장을 원천·소요로
